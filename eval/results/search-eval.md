**Reading the lexical rows.** BM25's 1.0 on out-of-scope is not skill: it returns
nothing whenever the query shares no terms with a manifest — which also happens on
13 of the 30 in-scope queries. On in-scope queries alone keyword leads BM25 (0.53
vs 0.43 at 22 commands), which is why keyword, not BM25, is Jev's fallback.

**What the Jev rows cost.** Latency is roughly flat in registry size (p50 253 → 272
ms from 22 → 87 commands); input tokens grow ~57 per registered command. These are
billed by TypeSafe and do not enter the agent's context. `fallbacks = 0` on both
Jev runs, so every Jev row is a real API measurement.

**Caveat.** 36 hand-written queries, written by the GAX author. The out-of-scope
"none" threshold (0.7) was tuned on the same six queries it is scored on.
